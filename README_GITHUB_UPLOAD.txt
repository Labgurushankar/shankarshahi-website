HOW TO ADD TO YOUR EXISTING GITHUB WEBSITE

OPTION A — Upload only the new form file
1. Open your website repository on GitHub.
2. Open the branch used by your website (usually main).
3. Click Add file > Upload files.
4. Upload:
      tb-lqas-form.html
5. Click Commit changes.

After deployment, the form should open at:
https://shankarshahi.com.np/tb-lqas-form.html

OPTION B — Add a menu/button on your existing homepage
Add this link inside your website navigation/menu:

<a href="/tb-lqas-form.html">TB LQAS Form</a>

Then commit the edited homepage/menu file together with tb-lqas-form.html.

IMPORTANT
- Do NOT replace your existing index.html unless you intentionally want to change the homepage.
- Place tb-lqas-form.html in the same root folder as your current index.html for the URL above.
- If your site uses a subfolder, update the link path accordingly.
- GitHub Pages / custom-domain deployment may take a short time to refresh after commit.
