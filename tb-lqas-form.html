Previous-year slide counts are linked automatically: Total = Negative + Positive. Enter Total + Negative to calculate Positive, or Total + Positive to calculate Negative. Annual Sample Size uses the supplied reference table (nearest annual negatives row and nearest SPR column). Quarterly sample is automatic by default but can be typed manually by unticking the checkbox. If Total Negative Slides are below 100 AND SPR is below 2.5%, both Annual Sample Size and Quarterly Sample Size show “All Slides”. In that special case Slide Interval = 1; otherwise Slide Interval = Last Quarter Slides ÷ Quarterly Sample Size.
