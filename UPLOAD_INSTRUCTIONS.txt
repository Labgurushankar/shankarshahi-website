SHANKARSHAHI.COM.NP — V5-STYLE VIRTUAL LAB FOR ALL TESTS

This package was rebuilt to match the uploaded Blood Glucose V5 simulator style:
- same Shankar Virtual Medical Laboratory look
- bench / instruments
- progress & assessment
- errors and score
- interactive sequence
- notebook / result calculation or interpretation
- print-friendly report sections

IMPORTANT: ALL TEST FILES ARE ROOT-LEVEL
This avoids the previous /virtual-lab/module.html 404 problem.

UPLOAD
1. Extract this ZIP.
2. Open your GitHub repository root.
3. Upload ALL .html files directly to the repository root.
4. Replace virtual-lab.html.
5. Commit changes.
6. Wait for GitHub Pages deployment and press Ctrl+F5.
