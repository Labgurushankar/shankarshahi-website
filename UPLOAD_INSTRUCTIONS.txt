CORRECTED RULE
Show “All Slides” when EITHER condition is true:

1. Total Negative Slides < 100
OR
2. Slide Positivity Rate (SPR) < 2.5%

Then:
- Annual Sample Size = All Slides
- Quarterly Sample Size = All Slides
- Slide Interval = 1

Only when BOTH conditions are not met will the normal lookup-table calculation be used.

EXAMPLES
- Negative slides = 80, SPR = 5.0%  → All Slides
- Negative slides = 150, SPR = 2.0% → All Slides
- Negative slides = 150, SPR = 4.0% → Normal lookup calculation
