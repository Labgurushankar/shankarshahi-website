This package keeps your existing website, TB LQAS page and first QC/QA/TQM presentation,
and adds FOUR more online view-only presentations.

PRESENTATION LIBRARY NOW INCLUDES
1. QC / QA / TQM — 64 slides
2. Standard, Calibrator & Control — 22 slides
3. Patient Preparation & Order of Draw — 27 slides
4. QC Sera Preparation & Monitoring — 49 slides
5. Standard Operating Procedure (SOP) — 34 slides

HOW IT WORKS
- Website menu has “Presentations”.
- Clicking it opens the Presentation Library section.
- Each card has “View Presentation”.
- Slides open in a browser viewer with Previous, Next, thumbnails and Full Screen.
- Original PPTX files are NOT included in the public website package.
- Direct PowerPoint download buttons are NOT provided.
- Basic right-click, print and Ctrl+S restrictions are included.
- No web page can make copying/screenshots technically impossible.

GITHUB UPLOAD
Repository:
https://github.com/Labgurushankar/shankarshahi-website

1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Click Add file > Upload files.
4. Upload EVERYTHING from the extracted folder, preserving folders.
5. When GitHub asks, replace index.html and existing presentation files.
6. Commit changes.

IMPORTANT FOLDER STRUCTURE
presentations/
  qc-qa-tqm/
  standard-calibrator-control/
  patient-preparation/
  qc-sera-monitoring/
  sop/

Do not rename these folders unless the viewer HTML links are also changed.
