5. Upload the generated index.html into repo ROOT. ALSO upload the virtual-lab folder into repo ROOT.
6. NEVER replace root index.html with virtual-lab/index.html.

8. Check homepage / and /virtual-lab/ and /virtual-lab/glucose/ after deployment.
